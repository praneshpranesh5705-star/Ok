# Day 02 — Focus Timer

A lightweight Pomodoro-style focus timer for study and work sessions.

## Features
- Focus, short-break, and long-break modes
- Start, pause, and reset controls
- Session and focus-minute totals saved in local storage
- Responsive layout for mobile and desktop
- No framework or build step required

## Run locally
1. Download or clone this repository.
2. Open `day-02-focus-timer/index.html` in a browser.
3. Choose a mode and press **Start**.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — timer logic and saved statistics
