# Day 7 — LearnLoop

LearnLoop is a self-contained flashcard learning app for short daily study sessions.

## Features

- Reveal/hide flashcard answers
- Again, Good, and Easy review actions
- Review count and Easy streak
- Progress indicator
- Add your own flashcards
- Delete cards
- Saves cards and progress in browser local storage
- Responsive mobile-friendly interface
- No frameworks, build tools, or external dependencies

## Run

Open `index.html` directly in any modern browser, or serve the folder with a simple local server.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Files

- `index.html` — app structure
- `styles.css` — responsive styling
- `script.js` — flashcard logic and local storage
