# Day 6 — HabitForge

HabitForge is a polished habit-tracking dashboard for building consistent daily routines.

## Features

- Daily habit check-ins with streak counters
- Momentum score and weekly activity view
- Add habits with category labels
- Remove habits without affecting other projects
- Light/dark mode
- Local storage persistence
- Responsive layout for mobile and desktop

## Run locally

No build step is required. Open `index.html` in any modern browser, or serve the folder with a local static server:

```bash
cd day-06-habitforge
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Tech

HTML, CSS, and vanilla JavaScript. No external dependencies.
