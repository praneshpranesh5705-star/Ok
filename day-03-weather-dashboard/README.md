# Day 03 — Weather Dashboard

A responsive weather dashboard built with plain HTML, CSS and JavaScript.

## Features
- City search with demo data
- Current temperature, humidity, wind and feels-like values
- 5-day forecast cards
- Celsius/Fahrenheit toggle
- Responsive mobile layout

## Run
Open `index.html` in any modern browser.

## Demo cities
Salem, Chennai, Bengaluru, Coimbatore and Mumbai.

## Live weather
The project intentionally uses local demo data. For production, replace the data object in `script.js` with a weather API integration.

## Project structure
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — search, forecast and unit-toggle logic
