# Day 4 — StudySprint

StudySprint is a polished focus and study dashboard designed for students and self-learners. It combines a Pomodoro-style timer, daily task planning, weekly focus momentum, theme switching, and browser storage in one responsive interface.

## Features

- 25-minute focus timer with pause, resume, reset, and progress bar
- Daily task list with completion state, tags, and remove actions
- Add your own tasks with a simple prompt flow
- Weekly focus momentum chart
- Light/dark theme toggle
- Saves tasks, sessions, and focus minutes with `localStorage`
- Responsive layout for mobile and desktop

## How to run

1. Open `index.html` in any modern browser.
2. No build tool or server is required.
3. For best results, use a local static server such as VS Code Live Server.

## Folder contents

- `index.html` — dashboard structure
- `style.css` — responsive visual design
- `script.js` — timer, tasks, local storage, theme, and chart interactions

This is a self-contained static project and can be deployed directly to GitHub Pages or Vercel.
